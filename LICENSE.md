# Licensing information

No open-source license has been selected for the original BreadRelay project source. Its package metadata records `UNLICENSED`. This document records the current status; it does not grant a new reuse license or change rights that apply separately under GitHub's terms.

The public repository makes the implementation available for review. Public visibility alone is not an open-source license. See [GitHub's repository licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

Third-party components keep their own licenses. The Vite-generated module-preload helper's MIT notice is included in `public/THIRD_PARTY_NOTICES.txt` and the published static build. The locked build/test dependency declarations are recorded in [docs/dependency-licenses.md](docs/dependency-licenses.md); their license texts accompany their installed packages. Those declarations do not license the original project source.
