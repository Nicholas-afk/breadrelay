    What this plan checks

    Whole pickups, carrying limits, collection windows, return deadlines, and up to three stops per volunteer. It first schedules the most weight, then keeps earlier assignments, then reduces travel minutes. Equal results use a stable ID order.

    The unchanged plan keeps each starting route in its original order and drops a whole route if it no longer fits. The revised plan searches feasible routes under the current inputs.

    Travel minutes from each row location to each column location. Return travel can differ from outward travel. Replace these values by opening a complete round file.
